# Sprint 1 Git Lab

A simple calculator built to practice professional Git workflow.

## Features
- Addition, subtraction, multiplication, division
- Division by zero handling

## How to run
bash
javac Calculator.java
java Calculator
## Git workflow
- Conventional Commits (feat, fix, docs, chore, refactor)
- Feature branches + Pull Requests (no direct commits to main)

## What I learned
I resolved my first merge conflict by editing the conflict markers manually and committing the result.
